#### Condition codes and descriptions

These are the condition codes for specimens when caught and/or released:

| Condition code | Description |
| -------------- | ----------- |
| A0 | Alive but unable to describe condition |
| A1 | Alive and healthy |
| A2 | Alive, but injured or distressed |
| A3 | Alive, but unlikely to live |
| D | Dead |
| U | Condition, unknown |
