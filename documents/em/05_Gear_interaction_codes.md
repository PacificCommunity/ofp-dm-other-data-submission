#### Gear interaction codes

These are the gear interaction codes for species of special interest:

| Gear interaction code | Description |
| --------------------- | ----------- |
| IEN | Entangled in gear |
| IFB | Feeding on bait during set |
| IGO | Interacted with primary gear only |
| IHD | Hooked deeply - throat or stomach |
| IHE | Hooked externally |
| IHI | Hooked internally (mouth) |
| IHJ | Hooked in jaw (circle hook) |
| IHU | Hooked unknown |
