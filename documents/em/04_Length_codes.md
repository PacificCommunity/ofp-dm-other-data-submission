#### Length codes and descriptions

These are the length codes for specifying the type of length measurements for each specimen.

| Length Code | Description |
| ----------- | ----------- |
| UF | Upper jaw to fork in tail |
| LF | Lower jaw to fork in tail |
| TL | Tip of snout to end of tail |
| PF | Pectoral fin to fork in tail |
| NM | Not measured |
| OW | EM Analyst's Estimate |
