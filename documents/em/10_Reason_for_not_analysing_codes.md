#### Reason for not analysing a set

These are the codes for reasons for not analysing a set:

| Reason | Reason code |
| ------ | ----------- |
| Insufficient image quality from dirty lenses | R01 |
| Insufficient image quality from obstructions over lenses | R02 |
| No EM records available | R03 |
| Only partial EM records available | R04 |
